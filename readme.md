# CARDVISTA

## Tagline

Scan. View. Connect.

## Overview

CardVista is an AR-enabled digital visiting card platform that allows users to create, manage, scan, and share digital cards with interactive 3D visualization and immersive card experiences.

## Features

- **Digital Card Management:** Create, upload, edit, view, and delete digital visiting cards.
- **3D Visualization:** Explore interactive holographic cards with rotation, zoom, avatars, and voice introductions.
- **QR Code Scanning:** Scan cards using uploaded QR images or a webcam.
- **Interactive Contact Actions:** Access Call, Email, Website, Maps, LinkedIn, and Instagram.
- **Customizable AR Scenes:** Personalize environments, themes, background effects, and music.

## Tech Stack

- **React.js:** Build the interactive user interface.
- **Node.js & Express.js:** Run the backend server and develop APIs and request handling.
- **MongoDB:** Store user accounts, digital cards, and AR preferences.
- **Vite & Render:** Build, optimize, deploy, and host the application.
- **Three.js:** Create interactive 3D digital card visualizations and immersive scenes.

## How to Use

1. **Create or Upload a Card:** Add your digital visiting card details.
2. **Manage Cards:** View, edit, or delete cards through the dashboard.
3. **Scan QR Codes:** Upload a QR image or scan using a webcam.
4. **Explore 3D Scenes:** View and interact with cards in a 3D environment.
5. **Connect & Share:** Access contact links and share digital visiting cards.
